this is a Basics Java Mini Project. 
 Project Description
This is a simple Java console-based project that takes student details as input from the user and displays them in a formatted output.
 Features
- Takes student name as input
- Takes college name
- Takes branch name
- Takes CGPA
- Takes city
- Displays all information in a formatted way
- Technologies Used
- Java
- Scanner Class
-JDK 21 (or your installed version)
Concepts Covered
- Variables
- Data Types
- User Input using Scanner
- nextLine()
- nextDouble()
- Output Formatting
